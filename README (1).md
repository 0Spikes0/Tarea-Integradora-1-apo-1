# UniBot - Tarea Integradora

## Descripción

UniBot es un sistema de asistencia académica pensado para estudiantes de primer ingreso. La idea principal es que los estudiantes puedan hacer preguntas sobre temas de su carrera y recibir respuestas relacionadas con la información permitida para su contexto.

El sistema también tiene un administrador, que se encarga de gestionar los estudiantes, los temas permitidos y algunas tareas de control.

## Fase 1: Análisis y planeación

En esta primera fase se trabajó en entender el problema y organizar la solución antes de empezar con la programación.

Los puntos realizados fueron:

- Caracterización del sistema.
- Identificación de entradas, procesos y salidas.
- Identificación de los actores del sistema.
- Construcción del Product Backlog inicial.
- Organización del proyecto por fases.
- Elaboración del Diagrama de Casos de Uso.
- Organización de las tareas en un tablero Kanban.

## Actores

### Estudiante

El estudiante puede ingresar usando su código institucional y realizar consultas académicas. Las respuestas deben mantenerse relacionadas con su carrera y con los temas permitidos.

### Administrador

El administrador se encarga de gestionar los accesos de los estudiantes, actualizar los temas permitidos y revisar el estado de las sesiones.

## Product Backlog

Durante esta fase se definieron las principales necesidades del sistema:

- Ingresar como estudiante usando el código institucional.
- Consultar dudas académicas.
- Mantener el contexto según la carrera del estudiante.
- Registrar nuevos estudiantes.
- Actualizar los temas permitidos de cada carrera.
- Revisar el estado de las sesiones.
- Guardar información usando archivos locales.
- Mostrar mensajes claros cuando una acción funciona o presenta un error.
- Mantener separadas las diferentes partes del sistema para facilitar cambios posteriores.
- Proteger la contraseña del administrador usando una variable de entorno.

## Organización del proyecto

El desarrollo se plantea de manera incremental. La idea es avanzar por fases, agregando nuevas partes del sistema poco a poco y revisando cada etapa antes de continuar.

Para organizar las tareas se utiliza un tablero Kanban con las actividades del proyecto.

## Estado actual

Actualmente el proyecto se encuentra en la Fase 1, correspondiente al análisis y la planeación. En esta etapa todavía no se desarrolla el código fuente.

Los principales entregables de esta fase son:

- Diagrama de Casos de Uso.
